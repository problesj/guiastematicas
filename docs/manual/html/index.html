Manual

Manual de uso · Guías temáticas de Bibliotecas UCN

Este manual explica cómo usar la plataforma de guías temáticas según el rol de cada persona. Las pantallas se tomaron con los datos de ejemplo de la plataforma: los nombres y las guías que aparecen son ficticios.

Capítulo Para quién
1. Introducción Todas las personas: qué es la plataforma, roles, cómo entrar y qué ve el público
2. Funciones comunes del personal Administrador, editor y colaborador: mi perfil, contraseña, consultas y sugerencias
3. Manual del colaborador Colaborador (y también editor y administrador): editar el contenido de una guía
4. Manual del editor Editor (y administrador): crear y publicar guías, lista de recursos A-Z, autores y editoriales
5. Manual del administrador Administrador: usuarios, materias, apariencia, integraciones y conexión con otros sistemas
6. Preguntas frecuentes Todas las personas

Cómo leerlo. Los permisos se suman: el editor hace todo lo del colaborador, y el administrador todo lo del editor. Si eres editor, lee los capítulos 2, 3 y 4; si eres administrador, todos.

Formatos. El mismo contenido está disponible en Markdown (esta carpeta), en HTML con estilo wiki (esta versión) y en Word (Manual-Guias-tematicas-UCN.docx). Los dos últimos se generan con scripts/generar-manual.sh a partir de los archivos Markdown, así que basta con editar estos.
